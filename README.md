\# Student Data Management System in C 



A light, menu-driven CLI (Command Line Interface) application written in standard C for managing student records.



\## Features

\- \*\*Add Student:\*\* Register students with unique roll numbers and names.

\- \*\*Edit Student:\*\* Update an existing student's name by roll number.

\- \*\*Delete Student:\*\* Remove student records while safely shifting array memory.

\- \*\*List Students:\*\* Display formatted tables of all currently enrolled records.

\- \*\*Search Student:\*\* Quickly locate student details using their roll number.
